## Projects

### 1. [AI-Driven Predictive Infrastructure Risk Assessment and Societal Impact-Based Maintenance Optimization Framework (InfraRisk-AI)](./AI-Driven-Predictive-Infrastructure-Risk-Assessment-Framework)
An end-to-end AI and mathematical optimization framework that combines physics-informed Weibull survival curves, 5-state Markov chain deterioration models, CDC Social Vulnerability Index (SVI) equity weighting, and multi-objective evolutionary scheduling for regional civil infrastructure.

- **Folder**: [`AI-Driven-Predictive-Infrastructure-Risk-Assessment-Framework/`](./AI-Driven-Predictive-Infrastructure-Risk-Assessment-Framework)
- **Features**:
  - Predictive deterioration modeling with dynamic telemetry anomaly scaling.
  - Multi-dimensional societal consequence quantification (Emergency, Economic, SVI Equity, Environmental).
  - Constrained evolutionary genetic algorithm (NSGA-II) and TOPSIS decision prioritization.
  - Interactive web decision-support dashboard and RESTful API backend.
